REST API Documentation

Crypto Streaming Pipeline — Real-time trade metrics and analytics

GET/api/dashboard

Returns all dashboard data in a single response: metrics, timeseries, sparklines, alerts, arbitrage opportunities, and exchange stats.

Query parameters:
ParameterTypeDefaultDescription
windowint3Time window in minutes (1–30)
exchangestring—Filter by exchange: coinbase, binance, kraken
spike_symbolstring—Product for news_spike_vs_price (e.g. BTC-USD or BTC). Defaults to the busiest symbol in the window.

Example: GET /api/dashboard?window=5&exchange=binance&spike_symbol=ETH-USD

GET/api/candles

Returns OHLCV candles (1-minute buckets) for the specified symbol.

Query parameters:
ParameterTypeDefaultDescription
symbolstring—Filter by symbol (e.g. BTC-USD). Omit for all symbols.
windowint3Time window in minutes (1–30)
exchangestring—Filter by exchange

Example: GET /api/candles?symbol=BTC-USD&window=10

GET/health

Health check endpoint. Returns Kafka connectivity status and data freshness. Use for load balancers and monitoring.

Response codes: 200 = healthy, 503 = degraded (Kafka error or stale data)

Response schemas

/api/dashboard returns:

  • metrics — Per-symbol aggregations (trade_count, avg_price_usd, vwap_usd, volatility_usd, total_volume_qty, total_notional_usd, price_change_pct)
  • timeseries — 30-second price buckets per symbol
  • sparklines — Last ~20 price samples per symbol for inline charts
  • alerts — Volume spike alerts
  • arbitrage — Cross-exchange price spread opportunities
  • exchange_stats — Per-exchange trade counts and symbols
  • exchange_metrics — Per (symbol, exchange) avg_price, trade_count, volume for comparison charts
  • volume_timeseries — Total volume per 30-second bucket
  • recent_trades — Last 25 trades for ticker display
  • status — Kafka status, freshness, latency, totals
